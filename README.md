# Roua Bouhjar — Portfolio

A modern, animated personal portfolio for **Roua Bouhjar**, Software Engineer.

## Run locally

No build step is required. Open `index.html` in a browser, or serve the folder with any static-file server, for example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize the profile photo

Place your image at `assets/profile.jpg`. Until then, the portfolio displays a branded initials placeholder.
